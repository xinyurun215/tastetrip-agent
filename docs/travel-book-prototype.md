# 合味行册：已选路线的阅读视图

批准范围：把现有行程结果整理成中式册页，复用原数据和协商逻辑。宣纸、墨色、朱砂，中文竖排封面；桌面目录与册页并排，手机折叠目录、单页阅读。只借鉴书册组织和翻页方式，未使用参考视频素材或代码。

## 使用

- 多人成员结果有已选站点时，在「协商路线」点击「翻阅合味行册」。
- 无服务器密钥时，多人回退原本没有候选站点，不生成虚构行册。可用现有「预览断网回退」查看双人演示，行册会标「演示 / 备用数据」。
- 封面展示已有目的地、日期、时间窗、同行者、群体预算。缺失数据明示待补充；当前输入没有日期字段。
- 每站一页，保留顺序、时间、已有选点说明与来源。没有全员确认机制，所有行册始终是「行程草稿」。
- 花费读原候选数据，避免把规划器的缺省 0 误当免费；币种未提供时明确标注。priceLevel 不当成实际金额。
- 当前样例没有照片。只在已有 image.url / imageUrl / photo.url 时展示照片及来源链接，不从网络补图；加载失败显示说明。真实颜色不加滤镜。
- 目录跳页、前后页、左右方向键、Esc、原生 dialog 焦点约束；减少动态效果关闭翻页动画。
- 返回协商或修改保留原页面输入和协商状态。重开时重新从封面阅读，不保存阅读进度。

## 实现边界

新增 travelBook.js / travelBook.css；main.js 只接入结果快照、入口和返回焦点。无框架迁移、依赖增加、后端、上传、照片管理、账号同步或历史书架。多人成功生成结果后隐藏旧双人演示，避免两套路线入口同时出现。
