# 合味旅行回忆画册

## 入口与边界

画册入口位于现有第三步「协商路线」的路线结果之后。原有成员输入、推荐和协商逻辑保持原样。打开独立全屏画册视图后，返回、Esc 或关闭视图会恢复入口焦点；原页面和协商状态仍留在内存中。

书架包含四本明确标注的摄影示例（沿途、上海、香港、京都）与当前路线草稿。示例摄影不代表用户已到访，示例故事不代表真实经历，当前行程始终尚未全员确认。真实行程缺照片时显示缺失说明，不借用示例照片冒充实拍。

本轮仅阅读：没有照片选择、上传、编辑、保存、账号、服务器存储或跨设备同步。关掉页面会丢失当前规划状态，画册不承诺持久化。重新开册从封面开始。

## 书册交互

- 实体书架由窄摄影书脊、侧面、顶部纸边和水平承托线组成；选中抽出并转向摄影封面。
- 封面与内页属于同一本书。每片纸有正反两个面，绕左侧书脊在透视空间旋转；底页保持不动，纸面在旋转中出现阴影。封面打开后，书脊位于双页中央。
- 点击封面、点击左右纸页、书外前后页按钮、左右方向键和横向滑动均可操作。快连点在一次翻页完成前被忽略，避免正反页错配。
- 「放回书架」先合册，再旋转缩回原书脊位置；Esc / 返回行程可随时退出，包括动画中途。
- 减少动态效果直接完成状态变化，不播放三维运动。触摸竖向滚动不被劫持；长行程说明可在页内滚动。

## 验证证据

使用本机独立的 headless Chrome，通过本地 `?preview=offline` 进入现有流程，不配置密钥，不调用真实 Qloo，不操作用户原有浏览器会话。实际查看桌面与手机截图，以及录屏中的逐帧动作。

- 1440×1000 桌面：书架、抽册封面、开册、双页、透视中间帧、正反翻页与回架。
- 390×844 与 320×740 手机：双页布局、加载图片、触摸横划与无横向溢出。
- 21 项浏览器断言覆盖封面层级、图片成功加载、快连点、方向键、回架重开、动画中途退出、Esc 焦点、原输入/路线保留、触摸手势、减少动态效果和行程草稿标签。
- 单元测试覆盖路线快照忠实性、未知费用、URL 安全、文本转义、照片来源、示例素材存在与双面纸页成对结构。保留既有协商快照回归。

真实运行录屏 MP4 / GIF、桌面书架/封面/双页/翻页截图和手机截图另存 Library；CI 状态以最终提交的运行结果为准，不把测试数量当作视觉验收。
